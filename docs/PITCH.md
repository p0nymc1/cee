# CEE — 路演版

> 每一节对应一页幻灯片。技术细节见[技术白皮书](WHITEPAPER.md)，这里只讲清楚三件事：**为什么现在**、**我们做了什么**、**凭什么信**。

---

## 1 · 开场：一个真实的两难

某个周二凌晨，安全系统检测到针对 VPN 网关的密码喷洒攻击。

**检测是对的。** 攻击真的在发生，来源 IP 明确，置信度 97%。

自动处置系统按标准流程封锁了那个 IP。

三分钟后，**900 名远程员工全部掉线**——那个"攻击源"是公司自己的 VPN 出口地址。

---

## 2 · 问题不在模型不够聪明

行业目前的答案是"上更强的 Agent"。但上面那个事故里：

- 检测器**没有误报**
- 处置逻辑**没有写错**
- 换一个更聪明的模型，**结果完全一样**

因为问题不在判断，在**执行**。

> **正确的判断，仍然可以有灾难性的执行。**

这就是为什么大量企业买了自动化，却把它设成"只告警、不动手"——**能力买了，不敢用**。

---

## 3 · 现有两条路都走不通

| | 传统企业软件 | LLM Agent |
|---|---|---|
| 追求 | 零故障、可审计 | 零门槛、高智能 |
| 代价 | 每个流程都要人写死 | 黑盒、烧钱、会死循环 |
| 敢不敢碰钱和权限 | 敢 | **不敢** |

企业要的是第三条路。而这条路的关键，不在于让模型更聪明，**在于换一个地方用它**。

---

## 4 · 核心洞察：Agent 是解释器，CEE 是编译器

同一件事问 Agent 一万次，它**推理一万次**。

而那件事，第一次就已经想明白了。

| | Agent | CEE |
|---|---|---|
| 模型什么时候工作 | 每次执行都重新推理 | **只推理一次** |
| 模型产出什么 | 已经发生的动作 | **一份可审查的流程** |
| 能不能事前检查 | **不能**——计划只在执行中存在 | 能——计划是一份文件 |
| 跑一万次的成本 | 一万次模型调用 | 一次 |
| 出错时能不能复现 | 不能 | 能，逐字复现 |

**这不是让模型走开，而是让它做真正难的那件事——把一段混乱的人话变成一份正确的流程——并且只做一次。**

照着流程执行，本来就不该由模型来做。

---

## 5 · 实际怎么用

```
你说：  "报销超过一万要经理批，账户已关闭的一律不放款"
          ↓
        模型起草出一份流程
          ↓
        自动静态检查：有没有死循环、有没有指向不存在的步骤、参数对不对
          ↓
        拿去年真实数据重放：看它会做出什么决定
          ↓
        你看一眼，点头
          ↓
之后：  永远确定性执行，可审计、可复现、零模型成本
```

**模型在这条链路里不可或缺**——没有它，这一步得人来画流程图。

但它只出现一次，且它的产出**在生效前被完整检验过**。模型编造一个不存在的操作？当场被拒，连保存的机会都没有。

---

## 6 · 一个别人给不了的能力

上面第四步不是装饰，它是这套架构独有的东西：

> **改一条规则之前，先算出它会改变过去哪些决定。**

```
把审批限额从 $100 收紧到 $50
重放一笔已经放行的 $80 退款：
    放行  →  转人工
```

风控调参、阈值收紧、策略变更——今天都是"改完上线看看"。这里变成**改之前先看**。

Agent 做不到这件事，**不是因为不够聪明，是因为它的计划在执行中才存在**，没有可供检验的对象。

## 7 · 凭什么信：现在就能打开

**https://p0nymc1.github.io/cee/**

这个页面由 CI **每小时**在一台干净机器上重新跑出来，包括：

- 六类业务场景的完整执行记录，每一步走了哪条路都在
- 实时行情监控（真实数据，不是演示数据）
- 开场那个 VPN 事故的完整拦截过程

**页面上没有一个字是手写的。** 全部是真实运行的输出——这本身就是论据：一个主张"确定性"的项目，展示材料不该靠人工维护。

## 9 · 还差什么（下一阶段买什么）

诚实说清楚，因为这决定了投入的意义：

| 缺口 | 影响 | 需要 |
|---|---|---|
| 起草链路未经真实模型验证 | 逻辑与闸门已全部测试（用桩），但"模型第一次能不能写对"待实测 | 一次真实调用与调优 |
| 身份源未接入 | HTTP 层与引擎授权都已就位且默认拒绝，但接真实 JWT/mTLS 还需一份参考实现 | 接入样板 |
| 度量偏产出 | 量了省多少调用，没量漏了多少意图 | 诊断性指标 |

**前两项决定能不能进生产。**

## 10 · 适用边界与结束语

不夸大适用范围，这本身是可信度的一部分。

**不适合**真正一次性的探索——"帮我查查这个报错什么意思"。那类任务没有"编译"的价值，Agent 更合适。

**但企业要自动化的不是那类任务**，是**重复发生**的工作。而重复，正是"编译一次"最划算的地方。

> **Agent 把最不需要重复推理的场景，做成了每次都重复推理。**

---

在模型能力逐渐趋同的当下，护城河不再是谁的 Prompt 写得好。

> **是谁能让企业敢把权限交给自动化。**

CEE 的答案不是让模型更聪明，而是**换个地方用它**——让它设计流程，而不是每次替你按下执行键。
