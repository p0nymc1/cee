# Code of Conduct

## Our standard

This project is a technical space. Contributors are expected to be respectful,
assume good faith, and keep discussion focused on the code and the ideas.

Examples of acceptable behaviour: clear technical criticism, disagreement backed
by reasoning, and patience with newcomers. Examples of unacceptable behaviour:
personal attacks, harassment, demeaning or discriminatory comments, and
sustained disruption of discussion.

## Scope

This applies in all project spaces — issues, pull requests, and any other
channel that represents the project — and when an individual is representing the
project in public.

## Enforcement

Report unacceptable behaviour privately to the maintainer through a
[security advisory](https://github.com/p0nymc1/cee/security/advisories/new) (it
is a private channel; the security label is incidental) or a direct message.
Reports will be reviewed and acted on as the maintainer judges appropriate,
which may include warnings, edits, or bans from project spaces.

This is a lightweight adaptation of the spirit of the
[Contributor Covenant](https://www.contributor-covenant.org). As the project
grows a fuller version may replace it.
